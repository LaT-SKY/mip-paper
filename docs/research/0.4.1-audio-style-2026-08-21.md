# 0.4.1 Audio 样式/配色/灵敏度 — 调研 (2026-08-21)

> 来源 `c4ba7c52` 子代理报告精炼，覆盖管线、Schema、架构、性能、UI、迁移、测试。

## 1. 管线

`pw-cat --record + pw-metadata` → `audio-pcm.mjs` (8B/frame, tails 重组) → `audio-analyzer.mjs` (FFT 2048 Hann, 72 band 对数聚合 30-18000Hz, gate -72dB ceiling -18dB, spatial/temporal 0.68/0.16) → `audio-spectrum-service.mjs` 30Hz 节流 (34ms) → IPC `audio-spectrum-updated` → `audio-ribbon.mjs` (MIRRORED_GEOMETRY baseline70/amp52/40/exp0.68, Catmull→Bezier, FADE 70ms, silenceDelay/fadeIn/Out) → `panel.css` `.audio-ribbon` 104px + `var(--accent-audio-*)`。仅 `gain` 可调。

## 2. 推荐 Schema

```js
audio: {
  enabled:true, gain:1, silenceDelayMs:600, fadeOutMs:450, fadeInMs:160,
  style:'ribbon', // ribbon|bars|wave|mirror
  colorMode:'auto', // auto|manual
  colors:{ primary:'#ff3478', complement:'#4ae9b4', neutral:'#ffffff' },
  sensitivity:1, // 0.3..3 渲染侧指数
  height:104, // 48..200 px
  position:'bottom', // top|center|bottom
  barCount:36, // 16..72
  mirrored:true
}
```

`gain` 为 capture 侧线性增益，`sensitivity` 为渲染侧 `pow(v, exponent/sensitivity)` 曲线。

`normalizeAudioConfig` 宽容回退，`SCHEMA` 严格枚举；`colors` 仅 `manual` 时生效，`auto` 时保留但忽略。

## 3. 架构

**策略注册表（推荐）**：

```
src/renderer/audio/
  audio-ribbon.mjs
  renderers/ribbon.mjs / bars.mjs / wave.mjs
```

单一状态机 `createAudioRibbonState/applySpectrumSnapshot/advanceAudioRibbon`，`createAudioRibbonController` 按 `style` 热切换渲染器，`renderer.mjs` 契约不变。SVG 主路径，`bars` 用 flex `div` 0.2ms，CSS 用 `--audio-height` 与 `[data-position]`。

`colorMode==='manual'` 时跳过 `applyAccentState` 对音频变量的覆盖；备选渲染器自重写手动色。

## 4. 性能

- 现状 <0.6ms/帧（3×72 点串），30Hz 服务 + 70ms 插值，`drift 30fps` 已节流
- `bars` 更省（36 rect，无字符串拼接），`wave` 1-2 path 最省
- 预计算 `x=1000*index/71` 表，复用 path 缓冲，`viewBox 1000x140` + `preserveAspectRatio none`，`height` 走 CSS 变量，`position` 单写 `top`

## 5. 设置 UI

`SETTINGS_SECTIONS.audio` 拆为 `audio-core/audio-style/audio-color/audio-dynamics`。

```
[样式] [ribbon●][bars][wave][mirror] 位置[底部] 高度[104px] 柱数36 镜像✓  预览svg
[配色] 模式 (●自动 ○自定义)  auto 显示 accent 芯片，manual 显示 3×<input type=color>
[灵敏度] 滑条 0.3..3 (柔和→灵敏)  静音等待/淡入/淡出
```

预览：设置页内嵌迷你渲染器，合成扫频 15Hz，无需 IPC。

## 6. 迁移

- `DEFAULT_CONFIG.audio` 冻结新增，`SCHEMA.audio` 扩展，`normalizeAudioConfig` 实现范围/枚举/hex 校验
- `runtime-config.mjs` 镜像校验，`settings-fields.mjs` 新增 enum/number/color 并更新 `CONFIG_LEAF_KEYS` 穷尽
- `panel.css` 增加 `--audio-height` 与 `position` 修饰，`index.html` 保持单容器
- 增量、向前兼容，旧文件静默补齐。

## 7. 测试

- `audio-ribbon.test`：风格切换、height/position、colorMode、sensitivity 曲线、taper 帽
- `config.test`：边界/非法/旧配置兼容
- `settings-fields.test`：覆盖范围与枚举
- `renderer.test`：容器与 CSS 存在性
- 手工 probe 测 p50 <1.5ms，无回归。

## 8. 风险

PipeWire 缺失时合成数据预览；accent 协调告警；reduced-motion 直跳；DPI 分数缩放保持 viewBox。
