# Mip-Paper 0.4.0 KDE Scope (2026-08-20)

> Supersedes `0.4.0-compatibility-discussion.tmp.md`. Hyprland/GNOME/Niri deferred to 0.5.0+. Mainline is KDE-only from this point.

## Theme

**0.4.0 KDE Gallery & Polish Release** — KDE longitudinal deep dive. No new DE. Deliver the best wallpaper experience on KDE Plasma 6.

Selected at 2026-08-20:
- Theme: KDE longitudinal deep dive (recommended)
- Wallpaper: Gallery / favorites / history / smart crop preview, no video/slideshow in 0.4.0
- Information panels: Keep 4 cards, only visual & animation polish, no plugin system
- Hyprland code: Archive to `archive/hyprland-layer-shell-2026-08-20`, mainline purified to KDE-only

## Goals

- Make wallpaper management first-class: gallery with history, favorites, deduplication by `sha256:contentKey`, and cover-accurate preview per display `bounds×scaleFactor`.
- Polish existing rendering/panel/menu/appearance pipeline to a shippable KDE benchmark.
- Keep `main` clean: no `native/layer-shell-host`, no `layer-host.mjs`, no hyprland branches in `doctor`.

## Non-Goals

- Hyprland/GNOME/Niri adapters, layer-shell, native host, `build:native`.
- Video wallpapers, `org.kde.slideshow` slideshow.
- Panel plugin system or 5th card.

## Deliverables

1. **Archive** — `archive/hyprland-layer-shell-2026-08-20` branch retains 37 hyprland commits; this document + `_archive/0.4.0-compatibility-discussion-2026-08-17.md` for traceability.
2. **Gallery domain** — `src/wallpaper-gallery.mjs` under `$XDG_DATA_HOME/mip-paper/gallery/` with `index.json` (0600) and per-image `wallpaper` (0644), APIs: `list/import/setActive/remove/toggleFavorite/prune`.
3. **CLI** — `mip-paper wallpaper gallery list|set|favorite|remove|prune` + `wallpaper set` now imports to gallery and activates atomically.
4. **Settings UI** — Gallery grid, drag-drop, smart crop preview, favorite toggle via new `settings:gallery-*` IPC.
5. **Polish** — Panel/menu/appearance animation and surface refinement; `doctor` gallery check; guides and `CHANGELOG.md` update.

## Branching & Commit Discipline

- Development on `feat/0.4.0-gallery-polish`, never merging to `main` during development.
- One small feature per commit (12-14 commits planned), each green on `npm test && npm run check && bash -n bin/mip-paper`.
- `main` only merged via `merge --no-ff` after review at release.

## File System Contract

```
$XDG_DATA_HOME/mip-paper/
  wallpaper                 # active pointer (0644), backward compatible
  gallery/
    index.json              # 0600
    <shortHash>/wallpaper   # 0644, first 8 of sha256
    <shortHash>/metadata.json
  wallpapers/<displayId>/   # KDE per-display cache, unchanged
```

## Acceptance

- `npm test` green on feature branch; `doctor` shows no hyprland items; gallery import/activate/favorite/remove/prune covered by unit tests; settings grid renders and persists via IPC.
