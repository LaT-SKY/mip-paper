## 决策摘要 (2026-08-21 用户确认)

用户已确认 0.4.1 三大支柱（`ask` 问卷 2026-08-21）：

| 支柱 | 入选 | 0.4.1 范围 | 延期 |
| --- | --- | --- | --- |

## 现状基线（0.4.0 已交付）

- **配置**：`config.json` 7 顶层组（mouse/wallpaper/color/appearance/audio/frameRate/motion/panel/weather/menu），热加载，`migrateLegacyConfig` 已处理 `interactionEnabled→mouse` 与 `backdropBlurPx` 移除。
- **面板**：4 卡固定 `trapezoid`（`CARD_CENTERS` 0.22/0.78/0.145/0.855 + `COLLAPSE_VECTORS` 4 向），`panel-motion.mjs` 弹簧 `omega=2π*4.7`，`panel.css` 绝对定位，`panel.height/borderRadius/surfaceOpacity/shadowIntensity` 已可调但无单卡开关。
- **壁纸**：全局 `wallpaper.mode kde|manual + fit cover/contain/stretch/center + crossfadeMs 0-1200`，画廊 `gallery/index.json` 0600 + `sha256:contentKey` 去重 + 收藏/历史 50 条 + `list/import/setActive/toggleFavorite/remove/prune`，活指针单文件 `$DATA_HOME/mip-paper/wallpaper`（0644），`colorService` 已按 `displayId` 隔离。
- **音频**：`pipewire-audio.mjs` → `audio-pcm.mjs` → `audio-analyzer.mjs` (FFT 2048, 72 band, Hann, -72..-18dB) → `audio-spectrum-service.mjs` 30Hz 节流 → IPC → `audio-ribbon.mjs` 3 条 SVG path (`left/energy/right`) + `MIRRORED_GEOMETRY baseline 70/amplitude 52/40/exponent 0.68`，仅 `gain/silenceDelay/fadeIn/Out` 可调。

- **迁移原则**：旧 `config.json` 缺字段即注入默认值，行为与 0.4.0 1:1 一致；`mergeConfig` 深合并，`migrateLegacyConfig` 补齐 `cards/layout/customCard` 与 `wallpaper.perDisplay/assignments` 与 `audio.style/...`。
- **校验**：`SCHEMA` 新增 `panelLayout/panelCards/customCard.audioStyle/audioColorMode` 等枚举，非法值抛 `TypeError`；`normalizeAudioConfig/normalizePanelConfig` 宽容回退（磁盘读时不抛）。

## 交付清单（0.4.1）

1. **面板**：`panel-motion.mjs` 向量按 `id` 映射 + `enabled` 过滤；`panel-layout.mjs` 预设表（centers+vectors+css）+ `panel.css` 预设类；`panel.mjs` `visibleIds` 分支 + 自定义卡 `{{time}}/{{date}}` 渲染；`InformationService` 按可见性启停拉取；`settings-fields.mjs` 新增 `cardList` 类型与 4 子卡；缩略预览。
2. **壁纸按屏**：`config.mjs` `perDisplay/assignments` + `wallpaper-gallery.mjs` 保持不变 + `kde-wallpaper-sync.mjs` 按 `assignments[displayId] ?? assignments.all` 发布；`window-manager.mjs` `getWallpaperTransaction` 按屏返回；CLI `wallpaper gallery set <id> [--display all|<id>]` + IPC `settings:gallery-set-active(displayId)`；设置页作用域选择器。
3. **音频**：`audio-ribbon.mjs` 策略注册表（`renderers/ribbon|bars|wave`）+ `panel.css` `--audio-height`/`[data-position]`；`accent.mjs` 在 `colorMode==='manual'` 时跳过覆盖；`settings-fields` 四子卡 + 缩略预览。
4. **文档与测试**：三份子调研落盘；`config.test/panel-motion.test/settings-fields.test/renderer.test` 补齐；`CHANGELOG.md` 与 `docs/guides/configuration.md` 更新。

## 非目标

- Hyprland/GNOME/Niri、layer-shell、video/slideshow、任意 JS 小组件、每屏独立 `fit`、自由像素级布局编辑器。

## 分支与提交纪律

- 详见三份子文档的实施顺序与测试矩阵。

## 决策矩阵

*面板布局*：预设类（`trapezoid|grid-2x2|compact|stack`）优于自由拖拽——前者可控、可截图回归、与弹簧 `stagger` 正交；后者需碰撞检测与持久化复杂度，留 0.5.0。
*壁纸存储*：`config.assignments`（A 方案）优于 `gallery.assignedDisplays`（B 方案）——配置即真相，热加载已有，gallery 保持内容去重语义。
*音频渲染*：策略注册表 + SVG 主路径 优于单一 Canvas——三样式共享状态机，分支仅在控制器，`bars` 用 flex `div` 0.2ms，保留 `vector-effect` 与 accent 过渡。

## 验收标准

- `npm test` 全绿（含新增 `panel-cards`/`audio-style` 边界）；旧 `config.json` 无损加载。
- 设置页：面板拖拽排序即时预览、布局切换无闪、自定义卡 `{{time}}/{{date}}` 正确；壁纸作用域切换后 `coverInfoFor` 按屏计算；音频样式/灵敏度实时预览。
- 实机：双屏 KDE 6 Wayland（不同 `scaleFactor`）下各屏壁纸独立、强调色按屏隔离、隐藏卡不计入 `panelRequestsInteractiveFps`（空闲回落 30fps）、隐藏 `weather/tide` 后无 QWeather 请求。
