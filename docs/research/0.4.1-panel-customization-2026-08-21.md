## 3. 迁移

```js
function migratePanelConfig(panel){
  if(!isObject(panel)) return panel;
  let next=panel;
  if(!('layout' in next)) next={...next, layout: DEFAULT_CONFIG.panel.layout};
  if(!Array.isArray(next.cards)){
    next={...next, cards: DEFAULT_CONFIG.panel.cards.map(c=>({...c}))};
  } else {
    const ALLOWED=new Set(['time','weather','tide','calendar','custom']);
    const seen=new Set(), cleaned=[];
    for(const e of next.cards) if(isObject(e)&&ALLOWED.has(e.id)&&!seen.has(e.id)){
      seen.add(e.id); cleaned.push({id:e.id, enabled:e.enabled!==false});
    }
    for(const def of DEFAULT_CONFIG.panel.cards) if(def.id!=='custom'&&!seen.has(def.id)) cleaned.push({...def});
    next={...next, cards:cleaned};
  }
  if(!isObject(next.customCard)) next={...next, customCard:{...DEFAULT_CONFIG.panel.customCard}};
  else next={...next, customCard:{...DEFAULT_CONFIG.panel.customCard, ...next.customCard}};
  return next;
}
```

读时补齐、写时落盘，不主动回写噪音。

## 4. CSS 布局策略

```js
  trapezoid:{
    centers:{time:{x:.22,y:.24},weather:{x:.78,y:.24},tide:{x:.145,y:.585},calendar:{x:.855,y:.585},custom:{x:.50,y:.585}},
    vectors:{time:{x:-.46,y:-.28},weather:{x:.46,y:-.28},tide:{x:-.44,y:.18},calendar:{x:.44,y:.18},custom:{x:0,y:.22}},

    centers:{time:{x:.25,y:.28},weather:{x:.75,y:.28},tide:{x:.25,y:.68},calendar:{x:.75,y:.68},custom:{x:.50,y:.68}},
    vectors:{time:{x:-.30,y:-.30},weather:{x:.30,y:-.30},tide:{x:-.30,y:.30},calendar:{x:.30,y:.30},custom:{x:0,y:.30}},

  },
  compact:{/* 横排 */}, stack:{/* 单列 */}

```

- `trapezoid` 保留 `position:absolute`；`grid-2x2` 用 `display:grid; grid-template-columns:1fr 1fr; gap:18px; padding:10% 6%`，卡 `position:relative`，禁用 `display:none` 不占位。
- `--panel-shadow-size/radius/surface-alpha` 保持全局。

## 5. 运动/动画改法

- `centers` 按 `enabledCards` 动态生成；`vectors` 按 `id→vector` 映射；`requestExpanded` 仅对可见排序，`activateAt` 紧凑重编号；`isPanelAnimating/panelRequestsInteractiveFps/getCardTransforms` 仅检查可见；`resize/advance` 跳过隐藏。
- `trapezoid` 数值与原 `CARD_CENTERS/COLLAPSE_VECTORS` 一致，冻结单测 `progress 1.1957…` 不变。

## 8. 风险与测试

- 风险：`offsetWidth 0` 突跳、stagger 空洞、单测冻结漂移 → 缓解：跳过隐藏、紧凑编号、trapezoid 数值复刻。
- 测试：`config.test` 补齐/非法校验，`panel-motion.test` 新增 enabled 过滤/isAnimating，`renderer-panel.test` 验证 layout 类与热更新，和风禁用后无请求，截图回归 4 布局×2 主题。
