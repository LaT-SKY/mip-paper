# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a KDE-aware `light`/`dark`/`system` appearance mode with a default `0.72` wallpaper brightness multiplier, complete configuration hot reload, stable per-display accent identity, and a verified dark visual system.

**Architecture:** Keep configuration validation and the existing serialized runtime coordinator as the single source of truth. Add a focused KDE appearance watcher/parser that publishes a validated resolved theme, extend window-manager bootstrap/IPC with that state, and let each renderer update semantic CSS variables plus a Canvas brightness multiplier in place. Dynamic accents continue to analyze original wallpaper pixels; only final Canvas composition is dimmed.

**Tech Stack:** Node.js ES modules, Electron IPC/context bridge, Canvas 2D, CSS custom properties, KDE `kdeglobals`, `node:test`, existing debounced watchers and runtime coordinator.

---

## File Map

Create `src/kde-appearance.mjs` for strict KDE background-color parsing, WCAG relative luminance classification, and a generation-safe directory watcher that reports `light`/`dark` changes.

Create `src/appearance.mjs` for validated appearance-state derivation and a small coordinator that starts/stops the KDE watcher only in `system` mode, retains the last valid system result, and exposes the resolved renderer payload.

Modify `src/config.mjs` and `src/runtime-config.mjs` to add and validate `appearance.mode` and `appearance.dark.wallpaperBrightness`, while keeping `color.transitionDurationMs` as the only transition duration.

Modify `src/main.mjs`, `src/window-manager.mjs`, `src/preload.cjs`, and `src/preload.mjs` to include the resolved appearance payload in bootstrap and broadcast one runtime payload shaped as `{ config, appearance }`, and to reconfigure the appearance coordinator during hot reload and shutdown.

Modify `src/renderer/renderer.mjs` to validate/apply appearance state, interpolate Canvas brightness in the existing scheduler, and preserve original wallpaper analysis. Modify `src/renderer/panel.css` and `src/renderer/styles.css` to use semantic light/dark variables and explicit shared transitions; keep `src/renderer/index.html` structurally unchanged except for the theme root hook if needed.

Modify `README.md`, `README.en.md`, and the existing config/renderer tests. Add focused tests for `kde-appearance`, `appearance`, Canvas brightness math, config validation, IPC/bootstrap, hot reload, and documentation contracts.
